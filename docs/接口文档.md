# easyChat 接口文档

## 基本信息

- **Base URL**：`/v1`
- **Content-Type**：`application/json`
- **鉴权方式**：Bearer Token（在请求头中携带 `Authorization: Bearer <AccessToken>`）

## 统一响应格式

所有接口均以 HTTP 200 返回，通过 `code` 字段区分业务状态：

**成功（有数据）：**

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": { ... }
}
```

**成功（无数据）：**

```json
{
  "code": 200,
  "msg": "操作成功"
}
```

**失败：**

```json
{
  "code": 400001,
  "msg": "错误描述"
}
```

## 一、用户模块

### 1.1 发送验证码

```
POST /v1/user/sms
```

**鉴权**：无

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| telephone | string | 是 | 手机号 |

**请求示例：**

```json
{
  "telephone": "13800138000"
}
```

**成功响应：**

```json
{
  "code": 200,
  "msg": "发送验证码成功"
}
```

**错误码：**

| code | msg | 触发场景 |
|------|-----|----------|
| 400001 | 请求格式错误 | 参数绑定失败 |
| 400002 | 手机号格式错误 | 手机号不符合 11 位格式 |
| 400003 | 发送太频繁，请稍后再试 | 距上次发送不足 60 秒 |
| 500001 | 发送验证码失败:系统繁忙 | Redis 异常或短信发送失败 |

---

### 1.2 注册

```
POST /v1/user/register
```

**鉴权**：无

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| telephone | string | 是 | 手机号 |
| password | string | 是 | 密码 |
| nickname | string | 是 | 昵称 |
| sms_code | string | 是 | 短信验证码 |

**请求示例：**

```json
{
  "telephone": "13800138000",
  "password": "yourPassword123",
  "nickname": "张三",
  "sms_code": "123456"
}
```

**成功响应：**

```json
{
  "code": 200,
  "msg": "注册成功",
  "data": {
    "uuid": "U20260407xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    "nick_name": "张三",
    "telephone": "13800138000"
  }
}
```

**错误码：**

| code | msg | 触发场景 |
|------|-----|----------|
| 400001 | 参数校验失败:注册请求参数错误 | 参数绑定失败（缺少必填字段） |
| 400002 | 手机号格式错误 | 手机号不符合 11 位格式 |
| 400003 | 手机号已注册 | 该手机号已有账号 |
| 400004 | 验证码错误 | 验证码与 Redis 存储不匹配 |
| 400005 | 验证码已过期或不存在 | 验证码超过 5 分钟有效期 |
| 500001 | 注册失败，请稍后重试 | 数据库写入失败等系统异常 |

### 1.3 登录

```
POST /v1/user/login
```

**鉴权**：无

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| login_type | string | 是 | 登录方式：`"password"` 或 `"sms_code"` |
| phone | string | 是 | 手机号 |
| password | string | 条件必填 | login_type 为 `"password"` 时必填 |
| code | string | 条件必填 | login_type 为 `"sms_code"` 时必填 |

**请求示例（密码登录）：**

```json
{
  "login_type": "password",
  "phone": "13800138000",
  "password": "yourPassword123"
}
```

**请求示例（验证码登录）：**

```json
{
  "login_type": "sms_code",
  "phone": "13800138000",
  "code": "123456"
}
```

**成功响应：**

```json
{
  "code": 200,
  "msg": "登录成功",
  "data": {
    "uuid": "U20260407xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    "nick_name": "张三",
    "telephone": "13800138000",
    "access_token": "eyJhbGciOiJIUzI1NiIs...",
    "refresh_token": "eyJhbGciOiJIUzI1NiIs..."
  }
}
```

**错误码：**

| code | msg | 触发场景 |
|------|-----|----------|
| 400001 | 参数校验失败:登录请求参数错误 | 参数绑定失败或 login_type 不合法 |
| 400002 | 手机号格式错误 | 手机号不符合 11 位格式 |
| 400003 | 用户不存在 | 手机号未注册 |
| 400004 | 密码错误 | 密码登录时密码不匹配 |
| 400005 | 验证码错误或已过期 | 验证码登录时验证码无效 |
| 400006 | 用户已被禁用 | 用户被管理员封禁 |
| 500001 | 登录失败，请稍后重试 | 数据库查询失败、Token 生成失败等 |

### 1.4 刷新 Token

```
POST /v1/user/refresh
```

**鉴权**：无（依赖 RefreshToken 自身校验）

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| refresh_token | string | 是 | 登录时获取的 RefreshToken |

**请求示例：**

```json
{
  "refresh_token": "eyJhbGciOiJIUzI1NiIs..."
}
```

**成功响应：**

```json
{
  "code": 200,
  "msg": "刷新Token成功",
  "data": {
    "access_token": "eyJhbGciOiJIUzI1NiIs...",
    "refresh_token": "eyJhbGciOiJIUzI1NiIs..."
  }
}
```

**错误码：**

| code | msg | 触发场景 |
|------|-----|----------|
| 400001 | 请求格式错误 | 参数绑定失败 |
| 401002 | RefreshToken无效或已过期 | JWT 签名错误、已过期或 Redis 中不存在 |
| 500001 | 刷新Token时失败，请稍后重试 | JWT 解析系统异常或 Redis 异常 |

### 1.6 更新用户信息

```
POST /v1/user/updateUserInfo
```

**鉴权**：需要 AccessToken

**请求头：**

```
Authorization: Bearer <AccessToken>
```

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| nickname | string | 否 | 昵称 |
| email | string | 否 | 邮箱 |
| gender | string | 否 | 性别（"0" 男 / "1" 女） |
| signature | string | 否 | 个性签名 |
| birthday | string | 否 | 生日 |

所有字段均为可选，仅传需要更新的字段。未传或为空字符串的字段不会被更新。

**请求示例：**

```json
{
  "nickname": "新昵称",
  "email": "new@example.com"
}
```

**成功响应：**

```json
{
  "code": 200,
  "msg": "更新用户信息成功",
  "data": {
    "uuid": "U20260407xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
    "telephone": "13800138000",
    "nickname": "新昵称",
    "email": "new@example.com"
  }
}
```

**成功响应（无更新字段）：**

```json
{
  "code": 200,
  "msg": "更新用户信息成功"
}
```

**鉴权错误码**：同 1.5 获取用户信息。

**业务错误码：**

| code | msg | 触发场景 |
|------|-----|----------|
| 400001 | 请求格式错误 | 参数绑定失败（JSON 格式错误） |
| 500001 | 系统繁忙 | 数据库更新失败 |

## 二、管理员模块

> 以下接口均需管理员权限，请求头需携带管理员角色的 AccessToken。

### 2.1 获取用户列表

```
GET /v1/admin/getUserInfoList
```

**鉴权**：需要 AccessToken + 管理员角色（admin / superAdmin）

**请求头：**

```
Authorization: Bearer <AdminAccessToken>
```

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 是 | 页码（从 1 开始） |
| page_size | int | 是 | 每页条数（最大 100） |

**请求示例：**

```json
{
  "page": 1,
  "page_size": 10
}
```

**成功响应：**

```json
{
  "code": 200,
  "msg": "获取用户列表成功",
  "data": {
    "user_list": [
      {
        "id": 1,
        "uuid": "U20260407xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
        "nickname": "张三",
        "telephone": "13800138000",
        "email": "",
        "avatar": "https://ossapi.easyimpr.com/easychatava/default/default.png",
        "gender": 0,
        "signature": "",
        "birthday": "",
        "created_at": "2026-04-07T12:00:00Z",
        "deleted_at": null,
        "last_online_at": "2026-04-07T12:00:00Z",
        "last_offline_at": null,
        "is_admin": 0,
        "status": 0
      }
    ],
    "total": 1
  }
}
```

**成功响应（无数据）：**

```json
{
  "code": 200,
  "msg": "获取用户列表成功",
  "data": {

    "total": 0
  }
}
```

**user_list 字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 自增主键 |
| uuid | string | 用户唯一标识 |
| nickname | string | 昵称 |
| telephone | string | 手机号 |
| email | string | 邮箱 |
| avatar | string | 头像 URL |
| gender | int | 性别（0 男 / 1 女） |
| signature | string | 个性签名 |
| birthday | string | 生日 |
| created_at | string | 创建时间 |
| deleted_at | string/null | 删除时间 |
| last_online_at | string/null | 最后在线时间 |
| last_offline_at | string/null | 最近离线时间 |
| is_admin | int | 角色（0 普通用户 / 1 管理员 / 2 超级管理员） |
| status | int | 状态（0 正常 / 1 禁用） |

**鉴权错误码**：同 1.5 获取用户信息。

|------|-----|----------|

## 三、公共鉴权错误码

以下错误码适用于所有需要 AccessToken 的接口（标注"需要 AccessToken"的接口）：

| code | msg | 触发场景 |
|------|-----|----------|
| 401000 | AccessToken格式错误 | 缺少 Authorization 请求头，或格式不为 `Bearer <token>` |
| 401001 | AccessToken已过期或无效 | Token 签名无效或已超过 15 分钟有效期 |
| 400006 | 用户已被禁用 | 用户被管理员封禁，请求被中间件拦截 |
| 500001 | 鉴权失败，请稍后重试 | JWT 解析发生系统异常 |

---

## 四、Token 说明

| Token 类型 | 有效期 | 用途 | 获取方式 |
|-----------|--------|------|----------|
| AccessToken | 15 分钟 | 请求头携带，用于接口鉴权 | 登录 / 刷新 Token |
| RefreshToken | 7 天 | 用于换取新的 Token 对 | 登录 / 刷新 Token |

**使用流程：**

1. 调用登录接口获取 `access_token` 和 `refresh_token`
2. 后续请求在请求头中携带 `Authorization: Bearer <access_token>`
3. AccessToken 过期后（收到 `401001`），调用刷新 Token 接口换取新的 Token 对
4. RefreshToken 过期后需重新登录
