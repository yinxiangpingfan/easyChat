# 用户接口文档

## 概述

- **Base URL**: `/v1/user`
- **Content-Type**: `application/json`

---

## 1. 发送验证码

### 接口信息

- **URL**: `POST /v1/user/sms`
- **描述**: 向指定手机号发送验证码

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| telephone | string | 是 | 手机号（11位） |

### 请求示例

```json
{
    "telephone": "18309894438"
}
```

### 响应参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | int | 状态码 |
| msg | string | 状态信息 |
| data | object | 响应数据 |

### 响应示例

**成功响应**:
```json
{
    "code": 200,
    "msg": "发送验证码成功",
    "data": null
}
```

**失败响应**:
```json
{
    "code": 400003,
    "msg": "发送太频繁，请稍后再试",
    "data": null
}
```

### 错误码说明

| 错误码 | 错误信息 | 说明 |
|--------|----------|------|
| 200 | 发送验证码成功 | 成功 |
| 400001 | 发送验证码请求错误 | 请求参数格式错误 |
| 400003 | 发送太频繁，请稍后再试 | 60秒内重复发送 |
| 500001 | 发送验证码失败:系统繁忙 | 服务端错误 |

## 2. 用户注册

### 接口信息

- **URL**: `POST /v1/user/register`
- **描述**: 使用手机号注册新用户

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| telephone | string | 是 | 手机号（11位） |
| password | string | 是 | 密码 |
| nickname | string | 是 | 昵称 |
| sms_code | string | 是 | 验证码（6位） |

### 请求示例

```json
{
    "telephone": "18309894438",
    "password": "password123",
    "nickname": "用户昵称",
    "sms_code": "123456"
}
```

### 响应参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | int | 状态码 |
| msg | string | 状态信息 |
| data | object | 响应数据 |
| data.uuid | string | 用户唯一标识 |
| data.nick_name | string | 昵称 |
| data.telephone | string | 手机号 |

### 响应示例

**成功响应**:
```json
{
    "code": 200,
    "msg": "注册成功",
    "data": {
        "uuid": "U20260404123e4567-e89b-12d3-a456-426614174000",
        "nick_name": "用户昵称",
        "telephone": "18309894438"
    }
}
```

**失败响应**:
```json
{
    "code": 400002,
    "msg": "手机号格式错误",
    "data": null
}
```

### 错误码说明

| 错误码 | 错误信息 | 说明 |
|--------|----------|------|
| 200 | 注册成功 | 成功 |
| 400001 | 参数校验失败:注册请求参数错误 | 请求参数格式错误 |
| 400002 | 手机号格式错误 | 手机号不是有效的11位号码 |
| 400003 | 手机号已注册 | 该手机号已存在 |
| 400004 | 验证码错误 | 验证码不正确 |
| 400005 | 验证码已过期或不存在 | 验证码已过期或未发送 |
| 500001 | 注册失败，请稍后重试 | 服务端错误 |

## 3. 用户登录

### 接口信息

- **URL**: `POST /v1/user/login`
- **描述**: 用户登录，支持密码登录和验证码登录

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| login_type | string | 是 | 登录类型：`password` 或 `sms_code` |
| phone | string | 是 | 手机号（11位） |
| password | string | 条件必填 | 密码（login_type为password时必填） |
| code | string | 条件必填 | 验证码（login_type为sms_code时必填，6位） |

### 请求示例

**密码登录**:
```json
{
    "login_type": "password",
    "phone": "18309894438",
    "password": "password123"
}
```

**验证码登录**:
```json
{
    "login_type": "sms_code",
    "phone": "18309894438",
    "code": "123456"
}
```

### 响应参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | int | 状态码 |
| msg | string | 状态信息 |
| data | object | 响应数据 |
| data.uuid | string | 用户唯一标识 |
| data.nick_name | string | 昵称 |
| data.telephone | string | 手机号 |
| data.access_token | string | 访问令牌（15分钟有效） |
| data.refresh_token | string | 刷新令牌（7天有效） |

### 响应示例

**成功响应**:
```json
{
    "code": 200,
    "msg": "登录成功",
    "data": {
        "uuid": "U20260404123e4567-e89b-12d3-a456-426614174000",
        "nick_name": "用户昵称",
        "telephone": "18309894438",
        "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
        "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
    }
}
```

**失败响应**:
```json
{
    "code": 400004,
    "msg": "密码错误",
    "data": null
}
```

### 错误码说明

| 错误码 | 错误信息 | 说明 |
|--------|----------|------|
| 200 | 登录成功 | 成功 |
| 400001 | 参数校验失败:登录请求参数错误 | 请求参数格式错误 |
| 400002 | 手机号格式错误 | 手机号不是有效的11位号码 |
| 400003 | 用户不存在 | 该手机号未注册 |
| 400004 | 密码错误 | 密码不正确 |
| 400005 | 验证码错误或已过期 | 验证码不正确或已过期 |
| 500001 | 登录失败，请稍后重试 | 服务端错误 |

## 4. 刷新 Token

### 接口信息

- **URL**: `POST /v1/user/refresh`
- **描述**: 使用 RefreshToken 获取新的 AccessToken

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| refresh_token | string | 是 | 刷新令牌 |

### 请求示例

```json
{
    "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

### 响应参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | int | 状态码 |
| msg | string | 状态信息 |
| data | object | 响应数据 |
| data.access_token | string | 新的访问令牌（15分钟有效） |
| data.refresh_token | string | 新的刷新令牌（7天有效） |

### 响应示例

**成功响应**:
```json
{
    "code": 200,
    "msg": "刷新Token成功",
    "data": {
        "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
        "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
    }
}
```

**失败响应**:
```json
{
    "code": 401002,
    "msg": "RefreshToken无效或已过期",
    "data": null
}
```

### 错误码说明

| 错误码 | 错误信息 | 说明 |
|--------|----------|------|
| 200 | 刷新Token成功 | 成功 |
| 400001 | 发送验证码请求错误 | 请求参数格式错误 |
| 401002 | RefreshToken无效或已过期 | RefreshToken无效或已过期 |
| 500001 | 刷新Token时失败，请稍后重试 | 服务端错误 |

## 5. 鉴权说明

### AccessToken 使用方式

在需要鉴权的接口中，需要在请求头中携带 AccessToken：

```
Authorization: Bearer <access_token>
```

### Token 有效期

| Token 类型 | 有效期 |
|-----------|--------|
| AccessToken | 15分钟 |
| RefreshToken | 7天 |

### 鉴权错误码

| 错误码 | 错误信息 | 说明 |
|--------|----------|------|
| 401000 | AccessToken格式错误 | Authorization 头格式不正确 |
| 401001 | AccessToken已过期或无效 | Token 过期或无效，需要刷新 |
| 500001 | 鉴权失败，请稍后重试 | 服务端错误 |

### 鉴权错误响应示例

```json
{
    "code": 401001,
    "msg": "AccessToken已过期或无效",
    "data": null
}
```

## 通用说明

### 响应格式

所有接口统一返回格式：

```json
{
    "code": <状态码>,
    "msg": "<状态信息>",
    "data": <响应数据，失败时为null>
}
```

### 状态码规范

| 范围 | 说明 |
|------|------|
| 200 | 成功 |
| 400xxx | 客户端错误（参数错误、业务错误等） |
| 401xxx | 鉴权错误 |
| 500xxx | 服务端错误 |

### 手机号格式

- 必须为11位数字
- 以1开头，第二位为3-9

### 验证码说明

- 验证码有效期为5分钟
- 同一手机号60秒内只能发送一次验证码
- 验证码使用后自动删除
