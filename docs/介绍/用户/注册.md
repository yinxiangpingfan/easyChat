# 注册 — Register

## 功能概述

新用户通过手机号 + 短信验证码 + 密码 + 昵称完成账号注册。注册流程依次执行 **手机号格式校验 → 验证码校验（Redis 消费）→ 手机号唯一性检查 → 密码加盐哈希 → 数据库持久化**，确保每个手机号仅能注册一次，且密码以不可逆方式存储。

## 路由信息

```
POST /v1/user/register
```

中间件链：`TreaceLoggerMiddleware` → `RegisterHandler`（无 AuthHttpMiddleware）

## 完整实现流程

### 1. 中间件阶段

仅经过全局的 `TreaceLoggerMiddleware`，为请求生成唯一 `traceID`（UUID v4），注入 `context` 用于全链路日志追踪。

此接口面向未注册用户，不经过 Auth 认证中间件。

### 2. Handler 层 — 参数绑定

从请求体中 JSON 绑定 `RegisterRequest` 结构体：

```go
type RegisterRequest struct {
    Telephone string `json:"telephone" binding:"required"`
    Password  string `json:"password" binding:"required"`
    Nickname  string `json:"nickname" binding:"required"`
    SmsCode   string `json:"sms_code" binding:"required"`
}
```

四个字段全部为必填项。绑定失败时返回 `400001 — 参数校验失败:注册请求参数错误`。

### 3. Service 层 — 注册执行（五步操作）

`userService.RegisterService` 按顺序执行以下步骤：

#### 步骤一：手机号格式校验

```go
tools.IsPhone(req.Telephone)
```

使用正则 `^1[3456789]\d{9}$` 校验手机号是否为合法的 11 位中国大陆手机号。

- 格式不合法 → 返回 `400002 — 手机号格式错误`

#### 步骤二：短信验证码校验

```go
code, err := tools.VerifyCode(ctx, req.SmsCode, "verify:code:" + req.Telephone, u.redisClient)
```

从 Redis 中取出 `verify:code:{手机号}` 对应的验证码，与用户提交的 `sms_code` 比对：

- Key 不存在（redis.Nil）→ 返回 `400005 — 验证码已过期或不存在`
- 验证码不匹配 → 返回 `400004 — 验证码错误`
- Redis 异常 → 返回 `500001 — 注册失败，请稍后重试`
- 校验通过 → 从 Redis 中删除该验证码（一次性消费）→ 继续

#### 步骤三：手机号唯一性检查

```go
res := u.userRepo.IsTelephoneRegistered(ctx, req.Telephone)
```

通过 GORM 查询 `user_info` 表中是否存在该手机号的记录：

| 返回值 | 含义 | 处理 |
|--------|------|------|
| `0` | 手机号未注册（`ErrRecordNotFound`） | 继续注册 |
| `-1` | 数据库查询出错 | 返回 `500001` |
| `-2` | 手机号已存在记录 | 返回 `400003 — 手机号已注册` |

#### 步骤四：密码加盐哈希

分两步完成密码的安全处理：

**4a — 生成随机盐值：**

```go
salt := tools.GenerateSalt()
```

使用 `crypto/rand` 生成 16 字节随机数据，转为 32 位十六进制字符串。

**4b — MD5 加盐哈希：**

```go
req.Password = tools.PasswordHash(req.Password, salt)
// 内部实现：md5.Sum([]byte(password + salt)) → 32 位十六进制
```

将原始密码与盐值拼接后取 MD5 哈希，生成 32 位定长字符串存入数据库。盐值独立存储在 `salt` 列中，登录时用于重新计算哈希进行比对。

#### 步骤五：生成 UUID 并持久化

**UUID 生成规则：**

```go
uuid := "U" + time.Now().Format("20060102") + uuid.New().String()
```

格式为 `U` + 8 位日期 + UUID v4，示例：`U20260407a1b2c3d4-e5f6-7890-abcd-ef1234567890`。前缀 `U` 标识用户类型，日期部分便于快速识别注册时间。

**写入数据库：**

```go
u.userRepo.SaveUserInfo(ctx, model.UserInfo{
    Uuid:      uuid,
    Telephone: req.Telephone,
    Password:  req.Password,   // 已哈希
    NickName:  req.Nickname,
    Salt:      salt,
})
```

Repository 层通过 GORM `Create()` 将用户信息插入 `user_info` 表，`CreatedAt` 在 Repo 中自动设置为当前时间。其余字段（Email、Avatar、Gender 等）使用数据库默认值。

- 保存失败 → 返回 `500001 — 注册失败，请稍后重试`

### 4. 响应结构

```go
type RegisterResp struct {
    Uuid      string `json:"uuid"`
    NickName  string `json:"nick_name"`
    Telephone string `json:"telephone"`
}
```

返回 `200 — 注册成功`，携带新用户的 UUID、昵称、手机号。注册成功后用户需通过登录接口获取 Token。

## 数据库写入字段

| 列名 | 值来源 | 说明 |
|------|--------|------|
| uuid | `"U" + 日期 + UUID v4` | 用户唯一标识 |
| telephone | 请求参数 | 手机号，建有索引 |
| password | `MD5(原始密码 + salt)` | 32 位哈希值 |
| nickname | 请求参数 | 昵称 |
| salt | `crypto/rand` 16 字节 hex | 32 位盐值 |
| avatar | 数据库默认值 | 阿里云 OSS 默认头像 |
| gender | 数据库默认值 `0` | 男 |
| is_admin | 数据库默认值 `0` | 普通用户 |
| status | 数据库默认值 `0` | 正常状态 |
| created_at | `time.Now()` | 注册时间 |

## 核心设计

| 设计点 | 说明 |
|--------|------|
| 验证码前置 | 注册前必须通过短信验证码，确认手机号归属权 |
| 一次性验证码 | 校验通过即从 Redis 删除，防止同一验证码被重复使用 |
| 手机号唯一约束 | Service 层查库 + 数据库 `telephone` 索引双重保障 |
| 加盐哈希存储 | 密码经 MD5 + 随机盐值哈希后存储，数据库泄露时无法直接反推原始密码 |
| crypto/rand | 盐值使用密码学安全随机数生成，不可预测 |
| 日期嵌入 UUID | UUID 前缀包含注册日期，兼顾唯一性和可读性 |
| 注册不签发 Token | 注册成功后需单独调用登录接口获取 Token，职责分离 |

## 调用链路图

```
Client
  │
  ├── Body: { "telephone": "13800138000", "password": "abc123",
  │           "nickname": "张三", "sms_code": "123456" }
  │
  ▼
TreaceLoggerMiddleware   →  生成 traceID, 注入 context
  │
  ▼
UserHandler.Register     →  ShouldBindJSON 绑定四个必填参数
  │
  ▼
UserService.RegisterService
  │
  ├── [1] tools.IsPhone               →  正则校验手机号格式
  ├── [2] tools.VerifyCode             →  Redis GET + 比对 + DEL（一次性消费）
  ├── [3] userRepo.IsTelephoneRegistered  →  DB 查重
  ├── [4a] tools.GenerateSalt          →  crypto/rand 生成 32 位盐值
  ├── [4b] tools.PasswordHash          →  MD5(password + salt)
  └── [5] userRepo.SaveUserInfo        →  GORM Create 写入 user_info 表
  │
  ▼
JsonBack                 →  { code: 200, msg: "注册成功", data: { uuid, nick_name, telephone } }
```

## 涉及的 Redis Key

| Key | 操作 | 说明 |
|-----|------|------|
| `verify:code:{手机号}` | GET + DEL（本接口消费） | 校验通过后立即删除，一次性使用 |
